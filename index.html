You have an unfinished session. Resume where you left off?

How to use

English

  • Copy the entire SMS message from your meter token return message.
  • Paste it into the box below and click Start Inserting.
  • Press Next (or → / Space) after entering each token into the meter — it auto-marks as done.
  • Press Prev (or ←) to go back if you need to re-check.
  • Press C to copy, N for a new session.
  • Check current inserted sequence: press 889 on your meter.

বাংলা

  • আপনার মিটার টোকেন এর সম্পূর্ণ মেসেজটি কপি করুন
  • নিচের বক্সে পেস্ট করে Start Inserting এ ক্লিক করুন
  • মিটারে প্রতিটি টোকেন লেখার পর Next বা → চাপুন — স্বয়ংক্রিয়ভাবে সম্পন্ন হিসেবে চিহ্নিত হবে
  • বর্তমান Sequence Number চেক করার জন্য মিটারে 889 টিপুন
